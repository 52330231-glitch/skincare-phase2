# Glow&Care: Your Skin Guide

A modern web application designed to help users identify their skin needs and improve their skincare routine.

## Project Description
Glow&Care provides expert-curated tips and personalized skincare guidance in a user-friendly interface to help users navigate through different skin types and care solutions efficiently.

## Live Website
https://skincare-phase2.vercel.app/

## Setup Instructions
1. Clone the repository: 
   `git clone https://github.com/52330231-glitch/skincare-phase2.git`
2. Open the project folder.
3. Install dependencies: 
   `npm install`
4. Run the project: 
   `npm run dev`

## Technologies Used
- React.js
- Vite
- CSS3
- Vercel (Deployment)
